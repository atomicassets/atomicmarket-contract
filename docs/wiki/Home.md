# AtomicMarket

AtomicMarket is a marketplace smart contract for selling and auctioning
[AtomicAssets](https://github.com/atomicassets/atomicassets-contract) NFTs on Antelope chains.
This repository holds its source.

## Documentation

The validated, source-cited documentation for this contract lives in
[atomic-knowledge](https://github.com/atomicassets/atomic-knowledge):

- [Contract reference](https://github.com/atomicassets/atomic-knowledge/tree/main/reference/atomicmarket):
  actions, tables, fees and royalties, marketplaces, RAM, and the v2 changes
- [Guides](https://github.com/atomicassets/atomic-knowledge/tree/main/guides): sales, auctions,
  buyoffers, deposits, and querying the API

## Releases and migration

[CHANGELOG.md](https://github.com/atomicassets/atomicmarket-contract/blob/main/CHANGELOG.md)
records each release. Its 2.0.0 entry carries the v1 to v2 migration notes.
